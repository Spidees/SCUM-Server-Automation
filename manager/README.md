# SCUM Server Automation

The manager for SCUM dedicated servers: hosting, the admin panel, the live map, the Discord bot, the Field Console and plugins, in one signed program for Windows.

The download is a file on the [Releases page](https://github.com/Spidees/SCUM-Server-Automation/releases), not in this folder.

## Check the download

The SHA-256 of the file you downloaded must be the one above. On Windows:

```
Get-FileHash .\SCUM-Server-Automation-v6.2.0.zip -Algorithm SHA256
```

On Linux: `sha256sum SCUM-Server-Automation-v6.2.0.zip`.
