# SCUMSA Launcher

The free launcher for SCUM players: every server with your real ping, one press to join, and the right mods for each server.

The download is a file on the [Releases page](https://github.com/Spidees/SCUM-Server-Automation/releases), not in this folder.

## Check the download

The SHA-256 of the file you downloaded must be the one above. On Windows:

```
Get-FileHash .\SCUMSA-Launcher_1.0.9_x64-setup.exe -Algorithm SHA256
```

On Linux: `sha256sum SCUMSA-Launcher_1.0.9_x64-setup.exe`.
