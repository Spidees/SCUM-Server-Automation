# SSA Reporter

A small in-game mod that keeps your server's listing in the scumsa.com server browser live. Run it or the bridge, not both: the bridge has the same report built in.

The download is a file on the [Releases page](https://github.com/Spidees/SCUM-Server-Automation/releases), not in this folder.

## Check the download

The SHA-256 of the file you downloaded must be the one above. On Windows:

```
Get-FileHash .\SSAReporter-v1.0.4.zip -Algorithm SHA256
```

On Linux: `sha256sum SSAReporter-v1.0.4.zip`.
